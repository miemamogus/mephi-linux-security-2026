# ДЗ №1. Средства защиты GNU/Linux

Студент: М265894. Система: РЕД ОС 8.0.3. Выполнено 31.10.2026 на учебной виртуальной машине.

| Раздел | Реализация и проверка |
| --- | --- |
| 1 | user1, UID 1234, основная группа students; домашний каталог /home/user1, права 0700. Пароль установлен, chage -M 90 user1 задаёт срок 90 дней (принято за три месяца). |
| 2 | Поиск обычных файлов с битом 4000. В processes.out зафиксирован passwd с RUID 1234, EUID 0 и процессы существующего пользователя UID 1000. |
| 3 | /home/user1/lab-bin/cat-suid принадлежит root:students, права 4750. Обычный cat не читает /root/mephi-secret.txt (0600), учебная копия читает. |
| 4 | /home/user1/lab-bin/chown-cap имеет cap_chown=ep. user1 успешно изменил владельца /home/user1/cap-test.txt на root. |
| 5 | Правило /etc/sudoers.d/mephi-user1 разрешает date -s и date --set=. visudo проверил конфигурацию. Время установлено равным текущему через sudo от user1; результат в time-test.out. |
| 6 | Настоящий снимок рабочего стола РЕД ОС получен gnome-screenshot. Истории двух SSH-терминалов и вывод проверок сохранены. |

Настройки пользователей, групп, sudo, прав и файловых capabilities хранятся на диске и сохраняются при обычной перезагрузке. Проверка перезагрузкой не проводилась. Восстановление более раннего снимка ВМ откатывает изменения; создайте новый снимок после выполнения ДЗ.

В etc/shadow хеши паролей заменены на REDACTED перед публикацией. Поля срока действия сохранены. Оригинал остаётся только на ВМ. Это намеренное отличие публичного артефакта от исходного файла.

При поиске исключены виртуальные /proc, /sys и /dev. Недоступные пользовательские FUSE-монтирования перечислены в find-errors.out; полнота поиска внутри них не гарантируется. /etc/passwd обычно доступен всем, поэтому для демонстрации set-UID выбран отдельный файл root.

Учебные привилегированные копии оставлены для проверки задания. После сдачи следует снять set-UID и capability; копия cat предоставляет user1 чтение файлов с правами root. Каталог lab-bin принадлежит root, доступ ограничен группой students.

Репозиторий для сдачи: https://github.com/miemamogus/mephi-linux-security-2026 . Артефакты системных файлов находятся в каталоге etc/, включая дополнительное правило etc/sudoers.d/mephi-user1.
